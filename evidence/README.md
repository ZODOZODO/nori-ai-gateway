# 증거

정제 JSON과 단계별 GATE-REPORT.md만 보관합니다. 원시 OTR XML, SPEC 본문, 질문·답변·Prompt·자격 원문은 증거에 넣지 않습니다. 아직 실행되지 않은 업무 AC/ISO는 NOT_RUN입니다.

게이트 레코드는 `evidence/<stage>/runs/**`, `measurements/**`, `(?:AC|ISO)-[0-9]{2}(?:-[A-Z0-9]+)*` 문법의 leaf 디렉터리와 직접 생산 호환 경로 `perf/**`, `user-run/**`의 모든 JSON을 읽습니다. 파일명이나 `kind` 유무로 건너뛰지 않으며 기존 파싱·해시·레코드 검증을 그대로 적용합니다.

`gates/**`, 단계 루트의 배포/백업 설정 등 운영·파생 artifact는 레코드 조회 대상이 아닙니다. `ops/**`의 운영 원본은 명시적으로 ingest한 뒤 정본 저장 경로에서 읽습니다. 기존 증거의 바이트·경로·파일명·해시는 변경하지 않습니다.
